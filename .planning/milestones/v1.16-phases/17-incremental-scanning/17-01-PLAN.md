<objective>
Remove the LRU cache cap and implement incremental merge in SessionLogReader so that unchanged JSONL files are never re-parsed.

Purpose: The LRU cache (200 entries) covers only 6% of 3,103 files, causing constant eviction and re-parsing. The per-file fingerprint (modDate + fileSize) already works correctly — expanding the cache to cover all files means unchanged files hit the cache instantly. Additionally, `cachedAllEntries` is blown away on every invalidation, forcing a full re-merge even when only one file changed. An incremental dirty-flag approach rebuilds only what changed.

Output: Modified SessionLogReader.swift with unbounded cache and incremental merge; new tests proving the behavior.
</objective>

    6. **Rewrite `readAllUsageEntries()` for incremental merge:**
       ```swift
       func readAllUsageEntries() -> [AssistantUsageEntry] {
           lock.lock()
           pendingInvalidation = false
           lastCorruptLineCount = 0

           // Fast path: not dirty, return cached result
           if !isDirty, let cached = cachedAllEntries {
               lock.unlock()
               return cached
           }

           isDirty = false
           let jsonlFiles = discoverJSONLFiles()

           // Build set of current file paths for stale-entry removal
           let currentPaths = Set(jsonlFiles.map(\.path))

           // Remove cache entries for files that no longer exist
           let staleKeys = cache.keys.filter { !currentPaths.contains($0) }
           for key in staleKeys { cache.removeValue(forKey: key) }

           // Incremental rebuild: re-read all files through cachedRead
           // (which returns instantly for unchanged files via fingerprint)
           var allEntries: [AssistantUsageEntry] = []
           var seenMessageIds = Set<String>()

           for fileURL in jsonlFiles {
               let entries = cachedRead(fileURL)
               for entry in entries {
                   if seenMessageIds.insert(entry.messageId).inserted {
                       allEntries.append(entry)
                   }
               }
           }

           allEntries.sort { $0.timestamp < $1.timestamp }

           if pendingInvalidation {
               pendingInvalidation = false
               isDirty = true  // Re-mark dirty so next call rebuilds
               lock.unlock()
               return allEntries
           }

           cachedAllEntries = allEntries
           lock.unlock()
           return allEntries
       }
       ```

       The key insight: `cachedRead()` already does fingerprint checking. For unchanged files it returns cached entries in O(1). For changed files it re-parses. The "incremental" behavior comes from the per-file cache doing the right thing — we just stopped throwing it away.
