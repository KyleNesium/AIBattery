# Phase 12 — UI Design Contract

> Visual and interaction contract for Phase 12: Responsiveness.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> and `Utilities/ThemeColors.swift`. The contract exists to define what must
> be preserved, what interaction states are affected, and what "done" looks

## Interaction States

This phase directly affects the following interaction states. Each must behave exactly as described after fixes are applied.

### Panel Open (RESP-01, RESP-02)

| State | Visual Requirement |
|-------|-------------------|
| Idle (panel closed) | Menu bar shows star icon + metric percentage. No rendering activity. |
| Click — opening (< 50ms) | Panel appears at correct position below status item. Header + metric toggle + usage bars render immediately. |
| Click — opening (deferred, +1 frame) | InsightsView chart section renders after panel is on-screen (deferred via `DispatchQueue.main.async`). No visible layout jump. |
| Panel fully open | All sections visible. No hang. Scrolling is instant. |

**No-jump requirement (RESP-04):** The deferred `InsightsView` placeholder must be `EmptyView()` (zero height). If a visible height jump occurs from the resize observer firing, fall back to deferring chart data computation inside `InsightsView` rather than removing the view from hierarchy. Test for jump before shipping.

### Panel Close / Dismiss (RESP-01, RESP-03)

| Dismiss path | Visual Requirement |
|--------------|-------------------|
| Click status item (second click) | Panel disappears. `isPanelShowing = false`. Next click opens cleanly. |
| Escape key | Panel disappears. `isPanelShowing = false`. |
| Click outside panel | Panel disappears. `isPanelShowing = false`. |
| App deactivation | Panel disappears. `isPanelShowing = false`. |
| macOS system orderOut (window server) | Panel disappears. `isPanelShowing = false` via `PopoverPanel.orderOut` override callback. |

**Desync constraint (RESP-03):** After any of the five dismiss paths above, the next single click on the status item must open the panel. A double-click should never be required to re-open. The `onDismiss` callback on `PopoverPanel` must fire for ALL paths including system-initiated `orderOut`.

### Toggle Boolean Visual Contract

`isPanelShowing` is not user-visible directly, but its incorrect state produces the stuck-toggle symptom. The fix is internal — no new visual affordance is required. The user's observable contract is: one click = open, one click = close, always.

### Deferred Rendering States (RESP-04)

| State | Visual |
|-------|--------|
| `panelHasAppeared = false` (first frame) | `InsightsView` not rendered. Panel shows header + metric toggle + usage bars + token health + projects header. Height is the sum of visible sections. |
| `panelHasAppeared = true` (second frame, +1 run-loop) | `InsightsView` renders. Panel height grows if needed. Growth must not cause a visible snap or flash. |
| Panel dismissed (`onDisappear`) | `panelHasAppeared` resets to `false`. Next open starts from the lightweight first-frame state. |

## Animation Contract

Existing animation tokens must not be changed. This phase must not introduce new animation types.

| Token | Value | Used For |
|-------|-------|----------|
| `MotionConstants.standard` | `.easeOut(duration: 0.15)` | Section collapse/expand, settings panel toggle, account switch |
| `MotionConstants.snappy` | `.easeOut(duration: 0.1)` | Metric mode changes (scoped to ForEach only), session chevron navigation |

**Anti-patterns frozen out (from prior fixes — do not reintroduce):**

| Pattern | Status | Reason |
|---------|--------|--------|
| `Timer.publish` on SwiftUI struct | BANNED | Causes timer accumulation freeze across re-renders |
| `.transition(.opacity)` inside `TimelineView` | BANNED | Causes main-thread animation block on 10s ticks |
| `contentTransition(.numericText())` on infrequently-updating values | BANNED | Causes unnecessary layout work |
| `panel.isVisible` for toggle logic | BANNED | Tried in v1.9.4, made toggle WORSE — reverted |
| `.hidden()` for deferred sections | BANNED | `.hidden()` still renders; use `if`-branch instead |
| `GeometryReader` above leaf level in scrollable content | BANNED | Already removed for GaugeBar — do not reintroduce higher |
| `withAnimation(.repeatForever)` in data path | BANNED | Leaks global repeating animation transaction |

Source: RESEARCH.md Anti-Patterns, MEMORY.md Performance Fixes

## Sections Affected by This Phase

| Section | Requirement | Change |
|---------|-------------|--------|
| `PopoverPanel` (NSPanel subclass) | RESP-03 | Add `onDismiss: (() -> Void)?` property + `orderOut` override that calls it |

| `UsagePopoverView` or wrapping gate | RESP-04 | Add `@State private var panelHasAppeared = false`; gate `InsightsGate` behind `if panelHasAppeared`; flip via `DispatchQueue.main.async` in `onAppear`; reset in `onDisappear` |
