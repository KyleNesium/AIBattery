    ```swift
    // Build observed model list sorted by recency (most recent first) for dynamic probe fallback.
    var lastSeenByModel: [String: Date] = [:]
    for entry in allEntries {
        let existing = lastSeenByModel[entry.model]
        if existing == nil || entry.timestamp > existing! {
            lastSeenByModel[entry.model] = entry.timestamp
        }
    }
    let observedModels = lastSeenByModel.sorted { $0.value > $1.value }.map(\.key)
    if let accountId {
        RateLimitFetcher.shared.setObservedModels(observedModels, accountId: accountId)
    }
    ```

    Note: This runs inside the existing single-pass iteration section. However, for clarity and since allEntries is already in memory and sorted by timestamp, a separate small loop after the main pass is acceptable (O(n) where n = unique models, typically < 10). If preferred, the model tracking can be folded into the existing for-loop over allEntries by adding `lastSeenByModel[entry.model] = entry.timestamp` inside the loop body (last write wins since entries are sorted by timestamp ascending, so the last occurrence is the most recent).

    Choose the cleaner approach: fold `lastSeenByModel[entry.model] = entry.timestamp` into the existing for-loop at line ~91 (after `entriesByDate[dateKey] = bucket`), then after the loop compute observedModels from the map. This avoids a second pass.
